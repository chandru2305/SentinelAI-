## 1. ORIGINAL SENTINELAI VISION

SentinelAI is an **AI Security Platform** built specifically to protect AI-powered systems from runtime threats. 

### Core Product Architecture Flow

```
   AI Application / LLM / RAG / AI Agent
                     │
                     ▼
       ┌───────────────────────────┐

       └─────────────┬─────────────┘

                     ▼

       │  (app/ai_security/)       │

       │  • Heuristic Inspection   │
       │  • Semantic AI Evaluator  │
       │  • Risk & Policy Decision │
       └─────────────┬─────────────┘
                     │
         ┌───────────┴───────────┐
         ▼                       ▼
┌──────────────────┐    ┌──────────────────┐
```

SentinelAI is **NOT** a generic SOC platform, SIEM, network monitoring system, or traditional firewall manager. The SOC / Security Operations dashboard layer exists solely to support, monitor, and investigate events generated by the AI Security Engine.

---

## 2. CORE CAPABILITIES (IN-SCOPE)

The following capabilities form the primary identity of SentinelAI:

- **Prompt Injection Protection**: Direct & Indirect Prompt Injection detection.
- **Jailbreak Attack Defense**: Detection of DAN (Do Anything Now), Developer Mode, Persona Adoption, and Virtual Machine bypasses.
- **System Prompt Extraction Defense**: Prevention of system instruction leakage.
- **Sensitive Data & Exfiltration Protection**: Scanning prompts, contexts, and model outputs for secrets, API tokens, and PII exposure.
- **AI Agent Security**: Autonomous tool call inspection, destructive command prevention (`rm -rf`, `DROP TABLE`), code execution parameter auditing (`eval()`, `exec()`), and agent permission monitoring.
- **RAG System Protection**: Detection of document context poisoning and untrusted instruction injection.
- **AI Risk & Policy Engine**: Real-time risk evaluation (0-100), confidence scoring, and policy enforcement (`ALLOW` / `WARN` / `BLOCK`).
- **AI Security Telemetry**: Real-time WebSocket broadcasting of AI security events and investigation workflows.

---

## 3. SUPPORTING INFRASTRUCTURE

The following infrastructure components exist exclusively to support the AI Security Platform:

- **Authentication & Security**: JWT bearer authentication (`app/auth/`).
- **Database & Persistence**: SQLAlchemy ORM, SQLite fallback, and PostgreSQL support with Alembic migrations (`alembic/`).
- **Real-Time Telemetry Broker**: WebSocket `ConnectionManager` (`app/realtime/`).
- **SOC Telemetry UI**: Heatmaps, event feeds, and audit logs that display AI security events.

---

## 4. OUT-OF-SCOPE (DO NOT BUILD)

The following are strictly out-of-scope and must **NOT** become development priorities:

- Generic network monitoring & traffic sniffing.
- Port scanning & traditional network vulnerability scanning.
- Traditional firewall rule management & router configuration.
- Generic endpoint security (EDR/AV for host OS files).
- Traditional SIEM log collectors unrelated to AI applications.
- Decorative UI widgets with no real backend security data source.
