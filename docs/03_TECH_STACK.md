# SentinelAI - Technology Stack

## Overview

SentinelAI is built using a simple, modern, and production-ready technology stack. The goal is to build a complete Enterprise AI Security Platform while keeping development manageable.

---

# Frontend

**Framework**

* React

**Language**

* TypeScript

Purpose:

* Build the user interface.
* Display dashboards, alerts, reports, and AI Security pages.

---

# Backend

**Framework**

* FastAPI

**Language**

* Python

Purpose:

* Handle business logic.
* Expose REST APIs.
* Connect the frontend with the database and AI.

---

# Database

**Database**

* PostgreSQL

Purpose:

* Store users.
* Store alerts.
* Store incidents.
* Store AI findings.
* Store reports.

---

# Authentication

**Method**

* JWT (JSON Web Token)

Purpose:

* Secure user login.
* Manage authenticated sessions.
* Protect APIs.

---

# Artificial Intelligence

**AI Provider**

* Ollama (Local AI)

Purpose:

* AI Chat Assistant.
* Incident explanation.
* Security recommendations.
* Report generation.

The project must work locally without requiring paid AI APIs.

---

# Version Control

* Git
* GitHub

Purpose:

* Source code management.
* Collaboration.
* Version tracking.

---

# Development Environment

**IDE**

* Visual Studio Code

**AI Coding Assistant**

* GitHub Copilot

Purpose:

* Develop and maintain the project efficiently.

---

# Technology Principles

* Keep the project simple.
* Use only technologies required for Version 1.
* Avoid unnecessary dependencies.
* Build the project so it can run locally.
* Add new technologies only when there is a clear need.

---

# Final Technology Stack

| Component       | Technology         |
| --------------- | ------------------ |
| Frontend        | React + TypeScript |
| Backend         | FastAPI (Python)   |
| Database        | PostgreSQL         |
| Authentication  | JWT                |
| AI              | Ollama             |
| Version Control | Git + GitHub       |
| IDE             | Visual Studio Code |
| AI Development  | GitHub Copilot     |
